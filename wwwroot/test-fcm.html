🔔 FCM Client Test

Halaman standalone utk generate FCM token dari browser + subscribe/send test via backend dev endpoint. Bukan bagian dari PWA — cukup tools debugging.

1. Firebase Web Config

Ambil dari Firebase Console → Project settings (⚙️) → General → Your apps → Web app (kalau belum ada, klik </> Add app → Web) → Firebase SDK snippet → Config.

2. Request FCM Token

Klik → browser minta izin notif → generate token. Token muncul di kotak bawah.

(belum request)

(belum send)
